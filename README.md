## 💫 About Me

I build for the parts of NLP that don't have shortcuts yet — models that know when they're wrong, inference that holds up under real load, languages nobody's built tooling for. Most of my recent work lives there: tuning vLLM inference on H100s, calibration-based evaluation, and data pipelines for Tajik and Arabic built from raw source to 1B+ tokens — work I've done both solo and alongside teams who needed it to actually ship. I go deep on NLP, not wide on ML.
